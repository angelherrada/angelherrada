## Featured Projects

### [Heladería El Torcal](https://heladoseltorcal.es) — Full-Stack Production Platform
End-to-end digital storefront and internal workshop management platform running in production *(private repository)*.

- **Public Storefront & Reservations:** Interactive flavor catalog with allergen filtering, multilingual i18n (ES/EN/FR/DE/IT), cake reservation system, inline CMS editing, and mobile-first LCP optimizations.
- **Internal Workshop Panel (*Obrador*):** Formula/recipe management, daily production & batch traceability, ingredient documents, automated XLSX/PDF backup exports, and double-OTP authentication flows.
- **Infrastructure & Security:** Containerized with **Docker Compose** behind an **Nginx** TLS reverse proxy isolating public storefront and LAN/VPN-only admin networks, **Cloudflare** edge filtering, and automated **GitLab CI/CD** pipelines (type-checking, linting, Pest/Vitest testing, and zero-interaction VPS deployment).

---

### Booklet — Offline-First Reader & Library Manager
First **Flutter (Dart)** application, built for distraction-free offline reading without backend servers *(private repository, active development)*.

- **Reader & Library:** Native `.epub` and `.pdf` rendering with customizable typography/themes, author/collection organization, highlights, page notes, ratings, and reading progress tracking.
- **Local-First Persistence & Sync:** Powered by **Drift (SQLite)** and **Riverpod**, with optional personal Google Drive OAuth2 synchronization using timestamp-based conflict resolution.
